# Локальный перевод в штатных субтитрах IINA

Интеграция основана на ядре [Live Translation](https://github.com/KazKozDev/live-translation) и отдельном адаптере с плагином IINA. Перевод отображается обычной дорожкой внутри плеера. Оригинал можно включить второй дорожкой; отдельное окно поверх видео не требуется.

## Установка без терминала

Нужны Mac на Apple silicon, macOS 14+ и интернет для первоначальной загрузки. Заранее устанавливать Python, Homebrew, FFmpeg, Ollama и IINA не требуется.

1. [Скачайте установщик для Apple silicon](https://github.com/avslyv/live-translation-iina/releases/latest/download/Live-Translation-Installer-arm64.dmg).
2. Откройте DMG, затем **Live Translation Installer.app** внутри него.
3. Нажмите **Install**. Установщик покажет этапы загрузки и подготовит компоненты, плагин, фоновую службу и модели Whisper/Gemma.
4. Дождитесь завершения. Полностью закройте и снова откройте IINA; кнопка **Open IINA** откроет плеер.

Не извлекайте DMG во время установки. Первая загрузка моделей занимает несколько гигабайт. При обновлении сохраняются загрузки, настройки, локальный токен и кэш субтитров. Заменяемые настройки интеграции копируются в резервную папку.

Текущая общественная сборка подписана ad-hoc и не нотарифицирована Apple. Если macOS блокирует первый запуск, проверьте источник файла и следуйте [официальной инструкции Apple](https://support.apple.com/ru-ru/102445): **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Команды терминала для этого не нужны.

Отдельный **Live-Translation-IINA.iinaplgz** устанавливает только плагин. Если служба и модели ещё не подготовлены, используйте полный установщик. Подробности — в [руководстве установщика](docs/INSTALLER.md). Разработчики могут установить интеграцию из исходников через `./setup-iina.sh`; инструменты и проверки описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Начать просмотр

1. Откройте локальный видеофайл. По умолчанию включён перевод с английского на русский.
2. Плагин сначала ищет подходящие текстовые субтитры. Если их нет, распознаёт речь из выбранной внутренней звуковой дорожки. Для первого показа потребуется подготовить начальный участок.
3. В списке субтитров появится **Русский · Live Translation (локально)**. Для другого языка название изменится. Шрифт, размер, положение, видимость и задержку настраивайте обычными средствами IINA.
4. Откройте **Plugin → Локальный перевод → Настройки и кэш…**, чтобы выбрать источник, языки и модель или посмотреть подготовленные участки.

Подготовка идёт для всего файла, в том числе во время обычной паузы. Закрытие видео или отключение перевода останавливает новые вычисления; готовые фрагменты остаются на диске и используются при следующем открытии.

Процент и полоска покрытия показывают готовые части. **100%** означает, что все участки доступны из кэша. Пока подготовка не завершилась, перемотка в новый участок ставит его первым в очередь. Уже готовый участок не нужно распознавать и переводить заново.

Настройка **Ждать перевод при перемотке** позволяет плагину поставить видео на паузу до готовности выбранного участка и продолжить после подключения субтитров. Ваша собственная пауза сохраняется. Можно продолжить вручную, скрыть субтитры или выбрать другую дорожку — плагин учитывает этот выбор. Ошибка или ожидание дольше 45 секунд снимает автоматическую паузу. Выключите настройку, если предпочитаете смотреть без остановок во время подготовки.

Служба обслуживает **одно активное видео**. Независимые очереди для нескольких окон пока не реализованы; новое активное видео может сменить предыдущее задание.

## Настройки перевода

Измените параметры в боковой панели и нажмите **Сохранить**. Настройки сохраняются между запусками.

| Настройка | Что делает |
| --- | --- |
| **Что переводить → Автоматически** | Предпочитает подходящие текстовые субтитры; при их отсутствии использует выбранную звуковую дорожку. |
| **Текстовые субтитры** | Переводит выбранную текстовую дорожку; если её нельзя прочитать, показывает ошибку. |
| **Звук** | Распознаёт выбранную внутреннюю звуковую дорожку через Whisper. |
| **С языка / На язык** | Выбирает исходный язык и язык перевода. |
| **Локальная модель** | Показывает модели, уже установленные в Ollama. **Обновить** перечитывает список. Установщик готовит `gemma4:12b`. |
| **Оригинал и перевод** | Добавляет исходный текст во вторую штатную дорожку. Выбранная вами вручную вторая дорожка сохраняется. |
| **Ждать перевод при перемотке** | Управляет автоматической паузой для ещё не готового участка. |
| **Реплик в запросе** | Отправляет переводчику одну или четыре реплики за запрос. |
| **Словарь перевода** | Задаёт перевод имён и терминов: по одной паре `оригинал → перевод` на строку. |

Доступны 11 языков: английский, русский, испанский, немецкий, французский, итальянский, португальский, японский, корейский, китайский и украинский. Whisper Turbo остаётся полной многоязычной моделью; исходный язык передаётся распознаванию явно.

**Экспериментальная фильтрация тишины** выключена по умолчанию. **Осторожная фильтрация** использует локальную модель Silero и может пропустить окно целиком, если в нём не обнаружена речь. Если речь обнаружена, Whisper получает исходное аудио без вырезания пауз и склейки: временная шкала не сжимается. Очень тихая речь может быть пропущена. Этот режим не гарантирует устранение всех ложных фраз на музыке или шуме; при пропусках выключите его.

Ручной выбор другой основной дорожки сохраняется. Команда **Включить и показать перевод** в меню плагина снова выбирает его дорожку. **Остановить перевод** прекращает подготовку текущего видео.

## Источники и синхронизация

Поддерживаются внешние SRT/ASS/SSA и текстовые дорожки локальных контейнеров, включая SubRip/ASS/SSA и `mov_text`. Автоматический выбор пропускает созданные Live Translation субтитры и дорожки только с надписями/forced-фрагментами. OCR графических субтитров не выполняется.

Выбор другой внутренней аудиодорожки, текстового источника или задержки меняет задание. Эти параметры входят в идентификатор источника: перевод другой дорожки не подставляется вместо нужного. Пользовательская задержка субтитров применяется плеером один раз. Длинные реплики сохраняют интервалы даже при пересечении границы участка и повторном открытии кэша.

Сетевые URL, прямые эфиры, DVD-меню и внешние звуковые файлы не поддерживаются. BlackHole, запись микрофона и изменение системного аудиовыхода не нужны: FFmpeg читает выбранный поток непосредственно из файла.

## Сохранённые версии и постоянство результата

Во вкладке **Кэш** показаны модель, готовность и размер версии. **Использовать** выбирает сохранённый результат для открытого видео с подходящим источником; **Удалить** удаляет только эту версию. Другие версии и общий кэш распознавания сохраняются.

Готовые субтитры можно открыть при остановленном Ollama или недоступных старых весах. Сохранённые JSON обнаруживаются и без нового индекса. Совместимый кэш из 1.3.2 открывается для своей первой аудиодорожки только для просмотра: существующие JSON/SRT не переписываются, недостающие части не дополняются новой моделью. Для новой подготовки создаётся отдельная версия.

Ключ кэша учитывает содержимое видео, источник, задержки, языки, конкретные модели и движки, контекст, словарь и параметры распознавания. Переименование или перенос неизменённого файла позволяет использовать подходящий кэш. Смена модели, словаря или другого параметра генерации создаёт новую версию и сохраняет предыдущую. Показ оригинала и ожидание при перемотке не требуют заново переводить текст.

Перевод использует фиксированный seed `42`, температуру `0` и жадный выбор. Контекст берётся из соседних исходных реплик по времени, включая границы фрагментов. Он не зависит от переведённой истории и порядка перемоток. Модель возвращает структурированный ответ с идентификаторами; недостающие результаты повторяются отдельно, готовые не пересчитываются.

Сохранённая версия показывает тот же текст при повторном просмотре. Битовая идентичность нового вычисления на другом GPU или движке не обещается. Смена модели во время обработки не позволяет дописать новый результат в старый профиль; используйте **Повторить подготовку**.

Проверенные реплики появляются в SRT постепенно. В постоянный JSON записываются только завершённые 30-секундные участки. После перезапуска недописанный участок готовится снова, завершённые остаются доступными. Отдельный кэш распознавания позволяет использовать совместимый исходный текст после смены переводчика.

## Что работает локально

По умолчанию речь распознаёт `mlx-community/whisper-large-v3-turbo` через MLX/Metal, перевод выполняет `gemma4:12b` через Ollama. Для текстовых субтитров Whisper не нужен. Silero 6.2.1 с лицензией MIT включён в установщик, проверяется по SHA-256 и работает через PyTorch без загрузки из интернета.

Сначала готовятся текущая позиция, ближайшие 180 секунд и оставшиеся пробелы. Когда вперёд готовы хотя бы 60 секунд, распознавание может обрабатывать до четырёх будущих участков за загрузку Whisper, затем освобождать память для переводчика. Этот пакет распознавания отличается от настройки **Реплик в запросе**.

Сервис доступен только на `127.0.0.1:18743`, Ollama — на `127.0.0.1:11434`. Локальные вызовы обходят системный HTTP-прокси. Во время просмотра модели не скачиваются. Первоначальной установке нужна сеть. Без сообщений IINA подготовка прекращается через 12 секунд; после завершения и десяти секунд простоя модели выгружаются. Лёгкая служба остаётся доступной через LaunchAgent.

## Файлы и обслуживание

Основные файлы находятся в `~/Library/Application Support/LiveTranslate/`:

| Путь | Содержимое |
| --- | --- |
| `project/` | Установленный код и отдельное окружение Python. |
| `iina-plugin/` | Настроенная копия плагина. |
| `iina-settings.json` | Настройки и словарь. |
| `subtitles/index.json` | Индекс сохранённых версий. |
| `subtitles/<ключ>.json` | Завершённые участки, исходный текст, перевод, интервалы и профиль. |
| `subtitles/<ключ>/` | Штатные SRT перевода и оригинала. |
| `subtitles/recognition/` | Отдельный кэш распознавания. |
| `iina-worker.log`, `iina-worker.error.log` | Журналы службы. |
| `backups/` | Резервные копии заменяемых настроек. |

`~/Applications/Live Translation for IINA.app` проверяет совместимость службы и открывает IINA. Исходный `LiveTranslate.app` относится к режиму оверлея. Автозапуск — `~/Library/LaunchAgents/local.live-translation.iina.plist`. Checkout остаётся в выбранном каталоге; установленный runtime работает отдельно.

Установщик включает систему плагинов и передаёт токен только настроенной копии. В IINA 1.5+ требуется `file-system` для штатной загрузки субтитров; прямые обращения JavaScript к файловой системе из настроенной копии удалены. Состояние и управление требуют токена, публичный `/health` не раскрывает ваше видео. Сервис принимает JSON/form до 256 КиБ и отклоняет запросы с посторонним Origin.

Для просмотра терминал не нужен. При диагностике проверить доступность службы можно так:

```sh
curl http://127.0.0.1:18743/health
```

Проверить совместимость и при необходимости запустить установленную службу:

```sh
cd "$HOME/Library/Application Support/LiveTranslate/project"
./.venv/bin/python -m live_translation.service_control --ensure
```

Выгрузить службу из текущего сеанса launchd:

```sh
launchctl bootout "gui/$(id -u)/local.live-translation.iina"
```

Приложение запуска или следующий вход в macOS могут загрузить службу снова. Для полного отключения сохраните LaunchAgent и ссылку плагина в резервной папке и перезапустите IINA. Перед удалением моделей проверьте, не используют ли их другие приложения. Кэши и журналы содержат пути и текст вашего видео; просмотрите их перед публикацией в issue.

Автотесты запускаются из исходного checkout с зависимостями разработчика, а не из минимального окружения установленного приложения. Команды — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Проверки выпуска

Автоматизация Developer ID и нотарификации подготовлена, но реальному выпуску нужны сертификат с закрытым ключом и разрешённые учётные данные Apple. В этой сессии такой выпуск не проверен. Изоляция на текущей macOS не равна чистой macOS в новой VM: эта проверка остаётся отдельным незавершённым этапом. Подробности — в [RELEASE_SIGNING.md](docs/RELEASE_SIGNING.md) и [отчёте о холодной установке](docs/COLD_INSTALL_TEST.md).
