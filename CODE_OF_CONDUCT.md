# Community guidelines

Keep discussions respectful, specific, and useful to the project. Welcome people
with different backgrounds and experience levels. Critique ideas and code with
evidence, and assume good intent when asking for clarification.

Harassment, discrimination, threats, sexualized conduct, and publishing another
person's private information are not acceptable. Do not post private recordings,
transcripts, credentials, or personal file paths in issues or pull requests.

Maintainers may edit or remove harmful content, close discussions, or restrict
participation when needed to protect the community. Report concerns privately to
the repository owner using the contact information on their GitHub profile.
